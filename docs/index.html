Capabilities

Built as a Player engine, not a one-video demo.

The Player consumes a data-driven playable manifest and keeps storage, title metadata and production rights decisions outside the rendering component.

Playback controls

Play/pause, timeline, ±10 seconds, volume, mute, speed, fullscreen, replay and responsive controls.

Advanced seeking

Swipe seeking, accelerated hold-seek, scrub timestamps and scene-frame previews.

Mobile gestures

Single, double and triple-tap shortcuts plus brightness, volume and long-seek gesture zones.

PiP continuity

Preserves playback intent across Picture-in-Picture transitions.

Runtime resilience

Explicit loading, buffering, seeking, ended and error states with recovery and network feedback.

Episodes

A CinePlay harness proves movie and episode playback through one Player while preserving real episode gaps.

Cast boundary

Uses the browser Remote Playback boundary and guards local-only sources.

Subtitles

Known WebVTT tracks plus an experimental server-side Wyzie discovery/acquisition boundary.

Private by design

Media, subtitle sources and credentials stay outside the public repository.

Architecture

Source-agnostic by design.

In production, CineWatch TV's rights and playback authority decides whether content may be streamed. The Player consumes the authorized result.

Try the project

Run the actual Player locally.

GitHub Pages hosts this documentation only. The Player requires a Next.js server and a media file, so the repository intentionally does not publish a playable movie.

git clone https://github.com/Asleki/cinewatch-player-lab.git
cd cinewatch-player-lab && npm ci
cp .env.example .env.local
PLAYER_LAB_MEDIA_PATH=/absolute/path/to/movie.mp4
npm run dev
Use only media you are permitted to use. No qualification movie, creator master, provider key or private subtitle source is included in the repository.
